# Version gates

A best practice is only true for a range of Angular versions. Read `angular.major` in `.review/scope.json`, then apply this table before reporting anything.

Precedence when sources disagree: **project rules** (AGENTS.md, CLAUDE.md, lint config) > **Angular's own best-practices file for the installed version** (`angular.bestPractices` in scope.json — shipped inside `@angular/core` since v22) > **this skill's references**.

State checked on 2026-10-08 against the shipped `@angular/core@22.2.1` typings and the Angular changelog. Latest stable: 22.2. Support: v22 active, v21 and v20 LTS (v20 until 2026-11-28), ≤ 19 end of life. Next major (v23) planned around June 2027 — majors are now yearly.

## What changed, by major

| Major | Defaults and changes that move review rules |
|---|---|
| 17 | Built-in control flow (`@if`, `@for`, `@switch`) and `@defer` introduced. Standalone by default in **new projects** generated by the CLI. |
| 18 | Control flow and `@defer` stable. Zoneless available as experimental. |
| 19 | **`standalone: true` is the default** in decorators. `input()`, `output()`, `model()`, signal queries and `@let` stable. `linkedSignal`, `resource` experimental. |
| 20 | `effect`, `linkedSignal`, `toSignal` stable. **`NgIf`/`NgFor`/`NgSwitch` deprecated**. 2025 style guide: no `.component`/`.service` suffixes (`talk-card.ts` holds `class TalkCard`). Zoneless stable in 20.2. Legacy `@angular/animations` deprecated in 20.2 (removal planned for v23). Incremental hydration stable. |
| 21 | **Zoneless by default** for new apps (TestBed too). **Vitest** is the default test runner. Signal Forms experimental. `HttpClient` injectable without `provideHttpClient()`. Host bindings type-checked. |
| 22 | **OnPush is the default**: `ChangeDetectionStrategy.Default` is deprecated in favour of `Eager`, and `ng update` adds `Eager` to components that relied on the old default. `resource`, `rxResource`, `httpResource` **stable**. **Signal Forms stable** (`form()`, `[formField]`). `@Service()` decorator and `injectAsync()` stable. `strictTemplates` on by default; template `?.` now yields `undefined` instead of `null`. Fetch is the default HTTP backend (`withFetch()` deprecated). `debounced()` experimental. TypeScript 6 required. Angular ships its own Agent Skills (`npx skills add https://github.com/angular/skills`) — none for code review. |

## Rules that depend on the version

| Rule | Applies when | Behaviour |
|---|---|---|
| R-PERF-020 | major ≤ 21 | Missing `OnPush` on a non-trivial component → MAJOR. |
| R-PERF-020 | major ≥ 22 | Never ask for OnPush. `Eager`/`Default` → MAJOR in new code, MINOR in touched code (often added by `ng update`). |
| R-ARCH-010 | major ≥ 19 | `standalone: true` is noise → INFO. `standalone: false` / new `@NgModule` → MINOR. |
| R-ARCH-028 | major ≥ 17 (deprecation ≥ 20) | Legacy structural directives in new templates → MINOR. |
| R-SIG-001 / R-SIG-002 | major ≥ 19 | Signal inputs/outputs/queries in new code. Below 19 they are developer preview: INFO at most. |
| R-SIG-007 | major ≥ 22 → MINOR; 19–21 → INFO | `httpResource`/`resource` were experimental before v22. |
| R-SIG-009 | major ≥ 22 | Signal Forms suggestion for **new** forms only. |
| R-ARCH-034 | major ≥ 22 | `@Service()` suggestion, new services only. |
| R-ARCH-035 | major ≥ 20 | Legacy animations → MINOR (MAJOR when preparing v23). |
| R-PERF-035 / R-TEST-005 | `zoneless` is true | Plain-field updates in async callbacks freeze the view; `fakeAsync` needs zone.js. |
| R-PERF-016 / R-PERF-017 / H9-type SSR checks | `ssr` is true | Browser globals must be guarded. With `ssr: false`, direct `localStorage`/`window` access is fine. |

## False positives to avoid

- Signal reads in templates (`count()`) are not "function calls in templates".
- Missing `.component` suffix in a v20+ project is the current style guide, not an error. Mixed styles inside one folder is worth an INFO.
- Missing OnPush on v22+.
- `@Injectable({ providedIn: 'root' })` remains valid in v22 (constructor DI, advanced providers).
- Class-based guards and `@HostListener`/`@HostBinding` are **not deprecated**: suggest the modern form in new code only (MINOR / INFO).
- Existing reactive forms are valid: suggest Signal Forms only for new forms.
- A missing `provideHttpClient()` on v21+ when no HTTP feature is configured.
- `subscribe` on a one-shot `HttpClient` call does not leak durably (it completes); lower confidence instead of reporting a leak.

## When this file is stale

This table is a cache of facts that the framework owns. On a version newer than 22, trust `angular.bestPractices` first, and update this file in the same PR that bumps the skill's `metadata.angular` range.
